# Lucas Cristofer — Landing Page de links

Versão focada em conversão: copy orientada a problemas reais, proposta de valor clara, portfólio, oportunidades e redes sociais com ícones próprios em SVG.

## Rodar localmente

```powershell
npm.cmd install
npm.cmd run dev
```

Depois abra `http://localhost:5500`.

## Antes de publicar

Quando o portfólio estiver na Vercel, abra `script.js` e troque:

```js
const PORTFOLIO_URL = "https://github.com/LC-cristofer/portfolio-lucas";
```

pela URL final do portfólio.

A foto em `assets/lucas.webp` foi apenas redimensionada/otimizada a partir da foto fornecida pelo Lucas; não houve geração ou edição por IA.
